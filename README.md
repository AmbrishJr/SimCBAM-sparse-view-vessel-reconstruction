# SimCBAM: attention U-Nets for sparse-view vessel reconstruction

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23338018.svg)](https://doi.org/10.5281/zenodo.23338018)

Code for the manuscript

> A. Sivaprakash and U. M. Rajagopalan, *Comparative Evaluation of Attention-Enhanced U-Net Models for
> Reconstruction of Simulated Vascular Patterns under Sparse-View Sampling: Potential Relevance to
> Photoacoustic Tomography* (submitted, 2026).

The study compares five attention configurations in a common U-Net backbone (**Baseline**, **SE**, **CBAM**,
**SimAM** and a hybrid **SimCBAM**) for removing streak artifacts from vessel images reconstructed from
sparse-view Radon data with filtered back projection (FBP) at **32, 64 and 96 projection angles**. Models are
compared on PSNR, SSIM, trainable-parameter overhead, FLOPs and latency.

**Scope.** Sparse-view inputs are simulated with a 2D Radon transform, not with a photoacoustic
acoustic-propagation model. Detector bandwidth, attenuation, directivity, speed-of-sound variation and
measurement noise are not modelled. The results are therefore a comparison on a simplified vascular
reconstruction task with *potential relevance* to photoacoustic tomography (PAT). They are not a validation for
PAT and do not establish one attention mechanism as better in general.


## Dataset

The 4,400 vessel images (128 × 128; 4,000 train / 200 validation / 200 test) are **not redistributed here**.
They come from the publicly shared archive on CASMI Cloud (CAS Key Laboratory of Molecular Imaging) that accompanies

> T. Tong, W. Huang, K. Wang, et al. Domain transform network for photoacoustic tomography from limited-view and
> sparsely sampled data. *Photoacoustics* **19**, 100190 (2020).

Download: <https://www.radiomics.net.cn/owncloud/index.php/s/i68KkqfW2eqwGMZ>

Use of the images is subject to the terms of the original providers. Please cite Tong et al. if you use them.
After extracting the archive, the vessel images should be laid out as

```
data/Vessel/
├── train/        4000 × .tif
├── validation/    200 × .tif
└── test/          200 × .tif
```

The ground truth is the `.tif` image scaled to [0, 1]. Sparse inputs are generated by the code (next section).

```bash
python -m venv .venv && source .venv/bin/activate

```

A CUDA GPU is strongly recommended. The notebook also runs on Apple-silicon (MPS) or CPU, but slowly. `simcbam_train.py` refuses to train on CPU unless you pass `--allow-cpu`.

## Reproducing the results

### Option A: notebook (everything in one place)

```bash
export VESSEL_ROOT=data/Vessel   # folder with train/ validation/ test/
export SIMCBAM_OUT=runs/v3       # where .npy data, checkpoints, results and figures are written
jupyter lab notebooks/SimCBAM_v3.ipynb
```

Run the cells in order. Paths in the notebook are relative to `notebooks/` if the variables are not set.
The notebook:

1. checks the parameter counts against the manuscript (it stops if they differ);
2. generates the sparse FBP inputs once and stores them as float32 `.npy` files;
3. trains all 15 configurations (5 models × 3 angle settings) for each seed. Runs can be resumed: finished runs are skipped;
4. writes `summary_table.csv`, `paired_tests.csv`, `cost.csv` and the figures.

### Option B: command-line script

`simcbam_train.py` uses the same protocol and file formats, so results from both routes can be merged.
It expects the `.npy` files from step 2 of the notebook (run the notebook up to section 2 once).

```bash
python simcbam_train.py --out runs/v3 --smoke                  # 1–2 min environment check
python simcbam_train.py --out runs/v3 --seeds 0 1 2            # train (resumable)
python simcbam_train.py --out runs/v3 --seeds 0 1 2 --report   # summary_table.csv, paired_tests.csv, report.txt
python simcbam_train.py --out runs/v3 --cost                   # cost.csv (run once, on one GPU)
```

### Updating the tables in this README

```bash
cp runs/v3/results/{summary_table.csv,paired_tests.csv,cost.csv,report.txt} results/
python scripts/make_readme_tables.py
```

### Protocol

| Setting | Value |
|---|---|
| Forward model | `skimage.transform.radon`, 32 / 64 / 96 angles uniformly over [0°, 180°), `circle=False` |
| Network input | FBP (`iradon`, Ram-Lak filter) stored as float32, no 8-bit conversion |
| Backbone | U-Net, base width 32, 3 encoder stages + bottleneck + 3 decoder stages; attention after each of the 7 conv blocks |
| Extra trainable parameters vs Baseline | SE 13,568 · CBAM 14,254 · SimAM 0 · SimCBAM 686 (checked in code) |
| Loss / optimiser | MSE, Adam, learning rate 1e-3 with cosine decay, batch 16, 30 epochs |
| Checkpoint | lowest validation loss (the last-epoch score is also stored, for transparency) |
| Seeds | 0, 1, 2 (`random`, `numpy`, `torch` and the DataLoader shuffle generator) |
| Metrics | PSNR and SSIM (`skimage.metrics`, `data_range=1`) on outputs clipped to [0, 1], 200 test images |
| Statistics | paired per-image differences vs Baseline and vs CBAM: bootstrap 95% CI (2,000 resamples), Wilcoxon signed-rank, Holm correction |

`torch.backends.cudnn.benchmark = True` is enabled for speed, so repeated runs with the same seed can differ
slightly at the floating-point level. Variation between training runs is reported as the SD across seeds.

## Results

**Summary.** SE-U-Net gave the highest mean PSNR and SSIM at all three sampling levels: +0.55, +0.92
and +1.11 dB PSNR over the baseline U-Net at 32, 64 and 96 angles. SimCBAM-U-Net showed no advantage over the baseline. Its PSNR differed by 0.00 to −0.08 dB, and its SSIM was slightly lower at every sampling level. These
differences come from a simplified Radon/FBP task and do not establish a generally better attention mechanism.

**How the results were produced.** All runs (seeds 0, 1 and 2) and the cost measurements were made on
Google Colab with an NVIDIA Tesla T4 GPU (software versions: `requirements.txt`). They used the Colab variant of the
notebook, whose training code is identical to `notebooks/SimCBAM_v3.ipynb`; only the data and output paths differ.
Per-run results, including the per-image PSNR/SSIM values used for the paired tests, are in
`results/v3_*_seed*.json`.

The tables below are generated from the CSV files in `results/` by `scripts/make_readme_tables.py`.
Do not edit them by hand.

## Earlier pipeline (archived)

An earlier version of this repository stored the FBP inputs as 8-bit integers, which wrapped out-of-range
values, and used `circle=True`, which discarded image content outside the inscribed circle. Its code and
numbers are kept in [`archive_old_pipeline/`](archive_old_pipeline/) for the record. **They do not correspond to
the manuscript.**

## Demo (not part of the reported results)

[`demo/`](demo/) contains an interactive Gradio app and a CNN sparsity-level classifier from the earlier
pipeline. They are not described in the manuscript and were not used for any reported result. See
[`demo/README.md`](demo/README.md).
